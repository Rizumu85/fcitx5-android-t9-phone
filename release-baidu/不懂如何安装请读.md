# fcitx5-android-t9-phone 4.6.6 安装说明

这是面向物理九键安卓手机的 Fcitx5 输入法。本文件夹提供输入法本体和 Rime 插件。本版对应 rime-ice-t9-phone v3.2.2。

输入法通常会自动下载、校验和部署九键 Rime 配置；但国内网络或当前网络无法访问 GitHub 时，自动部署可能失败。遇到这种情况，请按下面的完整手动步骤操作，不要只反复点击“同步”。

## 下载文件

64 位手机（`arm64-v8a`）安装：

- `org.fcitx.fcitx5.android-4.6.6-arm64-v8a-release.apk`
- `org.fcitx.fcitx5.android.plugin.rime-4.6.6-arm64-v8a-release.apk`

32 位手机（`armeabi-v7a`）安装：

- `org.fcitx.fcitx5.android-4.6.6-armeabi-v7a-release.apk`
- `org.fcitx.fcitx5.android.plugin.rime-4.6.6-armeabi-v7a-release.apk`

两个 APK 必须选择相同架构。本版对应 **rime-ice-t9-phone v3.2.2**。

## 首次安装：自动方式

1. 安装同一架构的输入法本体和 Rime 插件两个 APK。
2. 打开输入法本体，按引导启用并选择小企鹅输入法。
3. 保持网络连接并打开任意文本框。输入法会自动选择 Rime，下载、校验并部署匹配的九键配置。
4. 等待【中文词库准备中】消失后即可输入。

国内网络暂时无法连接 GitHub 时不会反复弹错，也不会破坏已经可用的词库。首次安装若长时间无法完成，请使用下面的手动方式。

## 首次安装：网络失败时手动导入

1. 安装同一架构的输入法本体和 Rime 插件，并打开输入法本体完成系统启用。
2. 在系统输入法设置中确认小企鹅输入法已启用；在 Fcitx5 的【输入法】列表中添加【中州韵】。
3. 打开任意文本框，让输入法初始化一次。进入输入法工具栏【⋯】→【词库切换】；先看到词库页面后再复制文件，这样应用已经创建了目标目录。
4. 从 `rime-ice-t9-phone` 项目的 Releases 下载 v3.2.2 配置压缩包并解压。把解压后的所有文件和文件夹复制到：

   `Android/data/org.fcitx.fcitx5.android/files/data/rime`

   不要把外层目录再套一层。Android 11 及以上可用电脑 USB 文件传输或支持 Android/data 授权的文件管理器复制。Debug 包使用：

   `Android/data/org.fcitx.fcitx5.android.debug/files/data/rime`

5. 回到文本框，打开【⋯】→【词库切换】→【重新部署】，等待部署完成。
6. 重新进入【词库切换】，选择【拼音九键】、【笔画九键】或【注音九键】。配置部署不等于用户数据同步，手动导入后不需要点击【同步】。

常见错误：复制了压缩包外层文件夹、复制到了下载目录、APK 架构不一致、或只点击【同步】而没有点击【重新部署】。

## 从旧版升级

直接覆盖安装同一架构的 4.6.6 输入法本体和 Rime 插件即可，用户词库和设置会保留。

- 本版继续使用 rime-ice-t9-phone v3.2.2；已经部署该版本的用户无需重新下载或部署配置。
- 首次安装若国内网络无法下载，可从 rime-ice-t9-phone 项目的 Releases 获取 v3.2.2 配置包手动恢复。
- 普通打开输入法或切换拼音、笔画、注音不会再次部署；设置和用户词库会继续保留。

## 主要功能

- 拼音、笔画和注音九键，可分别设置默认简体或繁体。
- 中文连续联想、中文自定义词库和拼音英文词库。
- 普通英文九键与联想英文，支持下一词预测和本地词库学习。
- 中英文手写，支持钢笔/毛笔、候选确认、中文拼音读音提示、中文后续联想和实体九键快捷操作。
- 密码键盘、自定义字体与主题、文本编辑、剪贴板和可调整工具栏。
- 自定义按键音，并可通过【完整物理按键音】覆盖文本框外的返回、菜单、接听和挂断键。
- 在【关于】->【检查更新】统一检查输入法本体、Rime 插件和九键 Rime 配置更新。

完整按键规则和功能说明请查看项目主页 README。
