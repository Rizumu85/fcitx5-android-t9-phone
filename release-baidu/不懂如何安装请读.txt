fcitx5-android-t9-phone 4.6.1 安装说明

这是面向物理九键安卓手机的 Fcitx5 输入法。本文件夹提供输入法本体和 Rime 插件，九键 Rime 配置会由输入法自动下载、校验和部署。

====================
1. 下载文件
====================

64 位手机（arm64-v8a）：
1. org.fcitx.fcitx5.android-4.6.1-arm64-v8a-release.apk
2. org.fcitx.fcitx5.android.plugin.rime-4.6.1-arm64-v8a-release.apk

32 位手机（armeabi-v7a）：
1. org.fcitx.fcitx5.android-4.6.1-armeabi-v7a-release.apk
2. org.fcitx.fcitx5.android.plugin.rime-4.6.1-armeabi-v7a-release.apk

两个 APK 必须选择相同架构。本版对应 rime-ice-t9-phone v3.1.0。

====================
2. 首次安装
====================

1. 安装同一架构的输入法本体和 Rime 插件两个 APK。
2. 打开输入法本体，按引导启用并选择小企鹅输入法。
3. 保持网络连接并打开任意文本框。输入法会自动选择 Rime，下载、校验并部署匹配的九键配置。
4. 等待“中文词库准备中”消失后即可输入，无需复制配置文件、点“重新部署”、点“同步”或删除其他系统输入法。

国内网络暂时无法连接 GitHub 时不会反复弹错，也不会破坏已经可用的词库。首次安装若长时间无法完成，可在“关于 -> 检查更新”中手动重试九键 Rime 配置；完整手动恢复方法见项目主页 README。

====================
3. 从旧版升级
====================

直接覆盖安装同一架构的 4.6.1 输入法本体和 Rime 插件即可，用户词库和设置会保留。

- 已经使用 v3.1.0 配置：直接复用，不会重复部署。
- 仍使用 v3.0.0 或配置缺失、损坏：输入法会自动下载并事务式更新到 v3.1.0。

====================
4. 主要功能
====================

- 拼音、笔画和注音九键，可分别设置默认简体或繁体。
- 普通英文九键与联想英语，支持下一词预测和本地词库学习。
- 中英文手写，支持钢笔/毛笔、候选确认、中文拼音读音提示和实体九键快捷操作。
- 密码键盘、自定义字体与主题、文本编辑、剪贴板和可调整工具栏。
- 自定义按键音，并可通过“完整物理按键音”覆盖文本框外的返回、菜单、接听和挂断键。
- 在“关于 -> 检查更新”统一检查输入法本体、Rime 插件和九键 Rime 配置更新。

完整按键规则和功能说明请查看项目主页 README。
